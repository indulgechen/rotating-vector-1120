相位 θ = ωt + φ 是旋转矢量与 +x 轴的夹角；φ 是 t = 0 时的初相。周期 T = 2π / ω 等于矢量旋转一周的时间。

读图要点

HOW TO READ
  1. 旋转一周：矢量转过 2π，对应一个完整周期，x-t 曲线重复一次。
  2. 相位决定位置：初相位 φ 改变时，t=0 的矢量起点和曲线起点同时改变。
  3. 投影就是位移：矢量端点在 x 轴上的投影，与 x-t 曲线当前点的纵坐标始终相等。
